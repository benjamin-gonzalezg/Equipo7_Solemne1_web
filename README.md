# Destino Cordillera

**Asignatura:** Desarrollo de Aplicaciones Web
**Evaluación:** Solemne 1 — Equipo 7

## Descripción del sitio

Destino Cordillera es un sitio web de promoción turística para un destino ficticio de montaña. El sitio presenta la propuesta turística del lugar a través de cuatro secciones principales: una página de inicio con la presentación general del destino, un listado de panoramas y actividades para realizar, información sobre alojamiento y gastronomía local, y un formulario de reserva y contacto para que los visitantes soliciten información.

## Instrucciones para ejecutar o visualizar el sitio

1. Clonar o descargar este repositorio.
2. Abrir el archivo `index.html` directamente en cualquier navegador web (no requiere instalación ni servidor).
3. Navegar por el sitio utilizando la barra de navegación superior, disponible en todas las páginas.
